Install guide

From download to done in about a minute.

MyPresence installs directly from an APK file — no Play Store required. Follow these steps once, and you’re in.

Before you start

  • Android 7.0 (Nougat) or newer
  • An internet connection for sign-in
  • About 54.3 MB of free space
Download the APK

Your browser will keep the file in Downloads.

  1. 01

    Download the APK

    Tap Download the APK. Your browser saves MyPresence.apk to your Downloads folder. If it asks whether to keep the file, choose Keep or Download anyway — that’s the standard warning for any APK.

    MyPresence.apk Android package · v1.0.0
  2. 02

    Allow installs from your browser

    Android only installs apps from sources you approve. Open the setting below and allow the browser or file manager you used to download the APK.

    Settings› Apps› Special app access› Install unknown apps› Chrome or Files› Allow from this source
    Settings› Security› Unknown sources› On

    Menu names vary a little between phone brands — look for “install unknown apps” or “unknown sources.”

  3. 03

    Open the file and install

    Tap the download notification, or open Files by Google → Downloads (Samsung: My Files → Downloads). Tap MyPresence.apk, then Install. Confirm with your PIN or fingerprint if asked.

  4. 04

    If Play Protect warns you

    Because the app isn’t from the Play Store, Play Protect may scan it and show a warning. Tap More details → Install anyway. Only continue if you downloaded the file from this page.

  5. 05

    Sign in and you’re set

    Open MyPresence and sign in with your existing account, or create a new one. Your events, announcements, and profile will be right there.

    Forgot your password? Use the reset link on the login screen. You can delete the APK from Downloads afterward to save space.

Is installing an APK safe?

APK is Android’s standard app format. Android asks for extra permission because the app isn’t coming from the Play Store. The important thing is the source: only install the file from this page or from someone you trust in your organization.

Why does Android warn that the file can harm my device?

That’s a standard warning shown for any APK downloaded through a browser. It doesn’t mean the file is malicious. If you downloaded MyPresence from this page, choose Keep or Download anyway and continue.

Play Protect blocked the install. What now?

Tap More details → Install anyway. If that option isn’t offered, open the Play Store → your profile → Play Protect → the settings gear → turn off Scan apps with Play Protect. Install the app, then turn scanning back on. Only do this for a file you trust.

“App not installed” keeps appearing.

This usually means an older copy of MyPresence is installed with a different signature, or your phone is low on storage. Uninstall the old app, free up some space, then open the APK again. Your account data lives in the cloud, so signing back in is easy.

Do I need a Google account or the Play Store?

No. You can install and use MyPresence without a Play Store account. You only need an internet connection and your MyPresence login.

Can I install the APK on an iPhone?

No — APK files are for Android only. An iPhone version would need to be distributed through the App Store or TestFlight.

How do I update MyPresence later?

Download the newest APK from this page and install it over the current version. Your account and data stay in the cloud. If Android refuses because the app signature changed, uninstall the old copy first, then install the new APK.

Which Android versions are supported?

Android 7.0 (Nougat) and newer. Most phones released in the last several years will work.
